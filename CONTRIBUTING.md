# Contributing

Thanks for your interest in Robin. Please use the right place for the right thing, it keeps the repo manageable.

## Where to post

| What you have | Where it goes |
|---|---|
| A bug | [Issue](https://github.com/apurvsinghgautam/robin/issues/new) |
| A question or something not working for you | [Discussions → Q&A](https://github.com/apurvsinghgautam/robin/discussions/categories/q-a) |
| A feature idea | [Discussions → Ideas](https://github.com/apurvsinghgautam/robin/discussions/categories/ideas) |
| A typo or a minor code change | [Issue](https://github.com/apurvsinghgautam/robin/issues/new), not a pull request |

Before opening anything, please check [TROUBLESHOOTING.md](TROUBLESHOOTING.md). Most problems are Tor not finished bootstrapping, Ollama not reachable from inside Docker, or an expired API key.

Ideas that I decide to build get converted into an Issue, so the tracker stays a list of actual work rather than a wishlist.

## Pull requests

Pull requests are for real feature work. For anything small, open an Issue instead.

1. Create a new branch
2. Make your change
3. Push the branch
4. Open a pull request

**Please do not open multiple pull requests for related work.** If you are changing two or three things that belong together, put them in one pull request. Several small PRs against the same area are harder to review than one, and they usually end up blocking each other.

Automated checks run on every branch push and pull request. If they fail, the details are in the Actions tab.
